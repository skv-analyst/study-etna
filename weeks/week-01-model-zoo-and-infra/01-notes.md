## Глава 1. Общее знакомство + TSDataset

**Обязательный формат данных для ETNA** — датафрейм с тремя столбцами:
- `timestamp` — временная метка;
- `target` — то, что прогнозируем;
- `segment` — идентификатор ряда (если ряд один, по конвенции используют `'main'`).

**Создание объекта `TSDataset`** — два шага:
1. `TSDataset.to_dataset(df)` — превращает плоский датафрейм в датафрейм с мультииндексом (сегмент — верхний уровень
   столбцов, `feature` — второй уровень).
2. `TSDataset(df_multiindex, freq=...)` — оборачивает в сам объект `TSDataset`, обязательно указав частоту ряда
   (`'D'`, `'MS'` и т.д.).

**Ключевые методы `TSDataset`:**
| Метод | Что делает |
|---|---|
| `.to_dataset()` | плоский индекс → мультииндекс (staticmethod) |
| `.to_pandas(flatten=...)` | обратно в pandas: `True` — плоский индекс, `False` — мультииндекс |
| `.fit_transform(transforms)` | применяет список трансформеров (фичи, препроцессинг) |
| `.inverse_transform(transforms)` | обратные преобразования |
| `.make_future(horizon, transforms)` | строит датасет для будущего периода |
| `.train_test_split(...)` | train/test с учётом временной структуры |
| `.describe()` | сводка: длина ряда, пропуски, число сегментов, число регрессоров и т.д. |
| `.plot()` | визуализация ряда(ов) |

**Экзогенные переменные** — всё, что не `target`. Делятся по двум осям:
- откуда взялись: созданы трансформерами ETNA (внутренние: лаги, скользящие статистики) vs добавлены нами вручную
  через `df_exog` (внешние: курс доллара, тип магазина);
- известны ли в будущем: регрессоры (лаг — известен) vs не-регрессоры (скользящая статистика без лага — неизвестна
  в будущем, пока её саму не сдвинуть на лаг).

**Датасет-пример из книги**: месячные продажи вина в Австралии — виден нелинейный (затухающий) тренд и выраженная
годовая сезонность (пик в декабре, провал в январе). Лежит у нас в `etna-examples/data/monthly-australian-wine-sales.csv`.

Соответствующий ноутбук для сверки API: [`etna-examples/101-get_started.ipynb`](../../etna-examples/101-get_started.ipynb).
